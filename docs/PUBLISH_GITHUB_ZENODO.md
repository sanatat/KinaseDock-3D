# Publish this GitHub repository to Zenodo

1. Verify author name in `CITATION.cff`, exact methods/results against original local logs, and that no personal data or credentials were committed.
2. Where possible, upload compact original data such as plotting `*.xvg`, original RAMD MDP files, original docking scripts, and figure PNGs from Y700. Full large binary trajectories are not required for this small portfolio.
3. Open [Zenodo's GitHub settings](https://zenodo.org/account/settings/github/) and enable `sanatat/KinaseDock-3D`.
4. Create an actual **GitHub Release**, tag `v1.0.0`, on branch `main`.
5. Confirm the completed archive and DOI inside Zenodo. Add the *real* DOI in the next README/CITATION update; do not invent one.

This record should be described as **research software / computational pilot**. DOI minting does not represent peer review.
